Quick 3-Step Setup for Google Tasks + Gemini

  1. Go to the Google Cloud Console — Tasks API and click Enable.
  2. Go to Credentials → Create Credentials → OAuth client ID.
    • Choose Chrome Extension (and enter the Extension ID shown above) OR choose Web application and add the Redirect URI shown above under Authorized redirect URIs. (Using Web application is easiest across PC & Mac if your unpacked Extension ID differs!)
  3. Paste the Client ID above, click Save ID, and click Sign in with Google.
  4. In Google Gemini Extensions, make sure Google Workspace is enabled. Then just ask Gemini: "Add 'Call dentist' to my TaskList list in Google Tasks"!
